# Скіли Feededify: інструкція для адміна

Канонічна версія англійською: [README.md](README.md).

Плагін **`feededify`** містить скіл `optimized-field-prompt`. Він допомагає написати або виправити
промпт для поля Optimized feed (Products → Edit prompts). Агент пише й перевіряє промпт, а ти
вставляєш його в Prompt Studio, тестуєш і зберігаєш. До систем Feededify агент сам не підключається.

## Встановлення (один раз)

**Claude Code.** Виконай дві команди всередині Claude Code і перезапусти його:

```text
/plugin marketplace add feededify-tech/feededify-skills
/plugin install feededify@feededify-skills
```

Якщо перша команда падає з помилкою SSH, використай повну адресу:
`/plugin marketplace add https://github.com/feededify-tech/feededify-skills.git`.

- **Перевірка:** спитай агента «які в тебе скіли feededify?». У відповіді має бути `feededify:optimized-field-prompt`.
- **Автооновлення:** `/plugin` → Marketplaces → `feededify-skills` → Enable auto-update.

**Codex.** Завантаж репо (Code → Download ZIP) і скопіюй теку `skills/optimized-field-prompt` у
`~/.agents/skills/` (у старіших версіях `~/.codex/skills/`).

**claude.ai.** Запакуй теку `skills/optimized-field-prompt` у zip і завантаж у Settings → Customize → Skills.

Node 18+ бажаний (агент ним перевіряє промпт), але не обов'язковий.

## Як користуватись

**1. Дай агенту контекст фіду:**
- назву поля та мету («нове поле `material_short`, до 30 символів, для оверлеїв на банерах»);
- **Source attributes** і **мову** фіду (форма редагування фіду);
- 3–5 прикладів товарів **з різних категорій** (вкладка Products);
- якщо виправляєш поле: його поточний промпт і кілька поганих результатів.

**2. Отримай промпт.** Агент поверне назву поля, тип і текст промпту, перевірений на твоїх прикладах.

**3. Протестуй і збережи в Prompt Studio:**
1. Products → **Edit prompts** → додай або відкрий поле → встав промпт.
2. **Test draft prompts** на 3–5 товарах, краще не з тих, що були в прикладах.
3. Якщо щось не так, скинь результати агенту.
4. **Save.** Збереження перегенеровує це поле для **всіх** товарів фіду на наступному запуску.

## Приклади запитів

- «Додай поле `material_short`: основний матеріал, до 30 символів, для банерів. Source attributes: title, description, product_type, brand. Мова uk. Товари: 1) … 2) … 3) …»
- «Тайтли задовгі й часто починаються з назви магазину. Поточний промпт title: … Погані результати: …»
- «Додай `product_highlight`: 3–6 коротких фактів про товар для Google Shopping.»
- «Додай `custom_label_0` для поділу кампаній за групами: yoga, fitness equipment, balls, accessories, other.»
- «Перевір усі наші збережені промпти: …»

## Правила

- Порожнє значення позначається як `""`. Ніколи не пиши «return null» чи «N/A», бо це слово потрапить у фід.
- Колонки називай точно як у Source attributes. Плейсхолдерів `{{…}}` немає.
- Для кожного поля вказуй ліміт: символи або кількість пунктів.
- Мову виходу задає налаштування фіду. Якщо дані джерела іншою мовою (наприклад, російською у фіді `uk`), скажи про це агенту, і промпт попросить перекладати.
- Для `google_product_category` промпт не потрібен, тип ставиться окремо.
